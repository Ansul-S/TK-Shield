# Screenshots — capture guide

The main README links to four images in this folder. Capture them on your own display (Retina = crisp) and save
with these exact filenames so the README renders them:

| Filename | View | How to get there |
|---|---|---|
| `landing.png` | Landing / hero | Open `http://localhost:8000/` |
| `defender.png` | Defender risk result | Defender → search **turmeric** → open entry → **Quick risk check** (shows risk 73/HIGH + factor bars + WIPO-aligned recommendations) |
| `examiner.png` | Examiner verdict | Examiner → paste a neem-oil antifungal abstract → **Check novelty** (shows LIKELY NOT NOVEL + matching TK prior art) |
| `researcher.png` | Researcher analytics | Researcher (shows registry/corpus stats + **Documented communities & peoples**) |

**Capture tips**
- Use a ~1440×900 browser window for consistent framing.
- macOS: `Cmd+Shift+4` then `Space` to capture a window cleanly, or `Cmd+Shift+4` for a region.
- Keep them reasonably sized (≈1–2 MB each) so the repo stays light.

Once added, they appear automatically in the README "Screenshots" section.
